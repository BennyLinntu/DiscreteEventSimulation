NetworkSimulator
============================================================

Discrete-event simulation of a three-node service network with queue, Gantt, and utilisation charts.

REQUIREMENTS
- Windows 10 or Windows 11
- .NET Framework 4.8 (included with current Windows versions)

HOW TO RUN
1. Double-click Launch.cmd, or double-click NetworkSimulator.exe.
2. To run the built-in example:
   NetworkSimulator.exe --demo

FILES
- NetworkSimulator.exe       application
- *.dll                 required runtime libraries
- samples\              example data (when present)
- LICENSE.txt           MIT license

This application is portable. Keep the folder contents together when moving it.
No installation, administrator rights, or network connection is required.
